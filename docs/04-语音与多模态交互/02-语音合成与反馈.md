## 1. TTS 在无人机中的作用

### 1.1 为什么需要语音反馈？

```
无语音反馈:
  操作员: "起飞到20米"
  无人机: [静默起飞]
  操作员: "它听到了吗？在执行吗？高度多少了？"  ← 焦虑

有语音反馈:
  操作员: "起飞到20米"
  无人机: "收到，正在起飞到20米"    ← 确认
  无人机: "已到达20米高度"           ← 完成通知
  操作员: [放心]
```

### 1.2 语音反馈场景

| 场景 | 反馈内容 | 紧急程度 |
|------|---------|---------|
| 指令确认 | "收到，正在执行..." | 常规 |
| 任务完成 | "任务完成，已返回" | 常规 |
| 状态报告 | "电量60%，预计飞行15分钟" | 常规 |
| 异常警告 | "警告：电量低于30%" | 高 |
| 紧急告警 | "紧急：GPS信号丢失！" | 紧急 |
| 环境提示 | "前方检测到障碍物" | 中 |

### 2.2 Edge TTS 使用

```python
import edge_tts
import asyncio

class UAVVoiceFeedback:
    """无人机语音反馈系统"""

    def __init__(self, voice="zh-CN-XiaoxiaoNeural"):
        self.voice = voice

    async def speak(self, text):
        """语音输出"""
        communicate = edge_tts.Communicate(text, self.voice)
        await communicate.save("temp_audio.mp3")
        # 播放音频
        self._play_audio("temp_audio.mp3")

    def speak_sync(self, text):
        """同步语音输出"""
        asyncio.run(self.speak(text))

    def confirm_command(self, command):
        """确认指令"""
        self.speak_sync(f"收到，正在执行：{command}")

    def report_status(self, status):
        """报告状态"""
        self.speak_sync(f"当前状态：电量{status['battery']}%，"
                       f"高度{status['altitude']}米")

    def warn(self, message):
        """发出警告"""
        self.speak_sync(f"警告：{message}")

    def emergency(self, message):
        """紧急告警"""
        self.speak_sync(f"紧急：{message}！紧急：{message}！")
```

## 3. 自然语言状态报告

### 3.1 LLM 生成自然语言报告

```python
class NaturalLanguageReporter:
    """自然语言报告生成器"""

    def __init__(self, llm_client, tts_client):
        self.llm = llm_client
        self.tts = tts_client

    def generate_and_speak(self, state, context=""):
        """生成并播报自然语言状态报告"""
        prompt = f"""将以下无人机状态数据转换为自然简洁的语音报告。

状态数据: {json.dumps(state)}
上下文: {context}

要求:
1. 语言自然、简洁
2. 突出重要信息
3. 如有异常，语气应适当紧急
4. 适合语音播报（避免过长的句子）

输出纯文本，不需要 JSON。"""

        report = self.llm.generate(prompt)
        self.tts.speak_sync(report)
        return report
```

## 4. 紧急告警系统

### 4.1 告警级别

```python
class AlertSystem:
    """紧急告警系统"""

    ALERT_LEVELS = {
        "info": {"priority": 0, "repeat": False},
        "warning": {"priority": 1, "repeat": False},
        "critical": {"priority": 2, "repeat": True},
        "emergency": {"priority": 3, "repeat": True},
    }

    TEMPLATES = {
        "battery_low": {"level": "warning", "msg": "电量低于30%，建议返航"},
        "battery_critical": {"level": "critical", "msg": "电量严重不足，正在自动返航"},
        "gps_lost": {"level": "critical", "msg": "GPS信号丢失，切换至视觉定位"},
        "obstacle_detected": {"level": "warning", "msg": "前方检测到障碍物"},
        "geofence_approaching": {"level": "warning", "msg": "接近地理围栏边界"},
        "wind_high": {"level": "warning", "msg": "风速较大，请注意安全"},
        "motor_failure": {"level": "emergency", "msg": "电机故障，正在紧急降落"},
    }

    def __init__(self, tts_client):
        self.tts = tts_client
        self.alert_history = []

    def trigger(self, alert_type, details=""):
        """触发告警"""
        template = self.TEMPLATES.get(alert_type)
        if not template:
            return

        level = template["level"]
        message = template["msg"]
        if details:
            message += f"，{details}"

        # 记录
        self.alert_history.append({
            "time": time.time(),
            "type": alert_type,
            "level": level,
            "message": message
        })

        # 语音播报
        if level == "emergency":
            self.tts.emergency(message)
        elif level == "critical":
            self.tts.warn(message)
        else:
            self.tts.speak_sync(message)

        # 紧急告警重复播报
        if self.ALERT_LEVELS[level]["repeat"]:
            threading.Timer(5.0, self.trigger, args=[alert_type, details]).start()
```

## 5. 多模态反馈

### 5.1 视觉+语音反馈

```python
class MultimodalFeedback:
    """多模态反馈系统"""

    def __init__(self, tts_client, display_client):
        self.tts = tts_client
        self.display = display_client

    def feedback(self, message, level="info"):
        """多模态反馈"""
        # 语音
        self.tts.speak_sync(message)

        # 屏幕显示
        self.display.show_notification(message, level)

        # LED 指示 (如果有)
        if level == "emergency":
            self.display.set_led("red", blink=True)
        elif level == "warning":
            self.display.set_led("yellow", blink=True)
        else:
            self.display.set_led("green")
```

## 思考题

1. 在嘈杂环境中，如何保证语音反馈能被操作员听到？
2. 如何设计语音反馈的时机？太频繁或太稀疏各有什么问题？
3. 紧急告警应该重复播报几次？间隔多长？
4. 如何让语音反馈听起来更自然、更像人类对话？
5. 设计一个完整的无人机语音反馈系统。

<details>
<summary>参考答案</summary>

**1.** 策略：(1) 使用高音量和清晰的语音（选择适合噪声环境的 TTS 声音）；(2) 重要信息用视觉显示辅助（屏幕、LED）；(3) 使用骨传导耳机（不受环境噪声影响）；(4) 关键告警使用振动反馈。

**2.** 时机设计：(1) 指令执行时确认；(2) 任务完成时通知；(3) 定时状态报告（如每5分钟）；(4) 异常发生时立即告警。太频繁会干扰操作员注意力，太稀疏会让操作员缺乏态势感知。建议：常规信息用文字显示，重要/紧急信息用语音。

**3.** 建议：紧急告警重复 3 次，间隔 3-5 秒。之后每 30 秒提醒一次，直到操作员确认或情况解除。不同级别的告警有不同的重复策略。

**4.** 方法：(1) 使用高质量的 TTS 声音（如 ChatTTS、VITS）；(2) 添加适当的停顿和语调变化；(3) 根据内容调整语气（平静/紧急/友好）；(4) 避免过于机械的句式，使用多样化的表达。

**5.** 完整系统：(1) 消息队列管理不同优先级的消息；(2) 高优先级消息可以打断低优先级；(3) 语音+视觉+LED 多通道反馈；(4) 支持操作员静音/调节音量；(5) 关键告警有确认机制。
