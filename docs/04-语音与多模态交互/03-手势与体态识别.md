## 1. 手势控制概述

### 1.1 手势控制的优势

```
场景: 操作员在地面向无人机发出手势指令

传统方式: 拿出遥控器 → 切换模式 → 操纵摇杆
手势方式: 举起手 → 做手势 → 无人机响应

手势控制更直觉、更快速，适合近距离交互
```

### 1.2 常用手势映射

| 手势 | 含义 | 无人机动作 |
|------|------|-----------|
| 手掌张开 | 停止 | 悬停 |
| 手掌向前推 | 前进 | 向前飞行 |
| 手掌向后拉 | 后退 | 向后飞行 |
| 手指向左/右 | 转向 | 左转/右转 |
| 拇指向上 | 上升 | 增加高度 |
| 拇指向下 | 下降 | 降低高度 |
| 握拳 | 确认 | 执行当前任务 |
| 挥手 | 跟随 | 跟踪操作员 |
| 比心/拍照手势 | 拍照 | 拍摄照片 |

## 2. 手势识别技术

### 2.1 基于 MediaPipe 的手势识别

```python
import mediapipe as mp
import cv2

class GestureRecognizer:
    """基于 MediaPipe 的手势识别器"""

    def __init__(self):
        self.mp_hands = mp.solutions.hands
        self.hands = self.mp_hands.Hands(
            static_image_mode=False,
            max_num_hands=1,
            min_detection_confidence=0.7,
            min_tracking_confidence=0.5
        )
        self.mp_draw = mp.solutions.drawing_utils

    def recognize(self, frame):
        """识别手势"""
        rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        results = self.hands.process(rgb)

        if results.multi_hand_landmarks:
            hand_landmarks = results.multi_hand_landmarks[0]
            gesture = self._classify_gesture(hand_landmarks)
            return {"gesture": gesture, "landmarks": hand_landmarks}

        return {"gesture": None, "landmarks": None}

    def _classify_gesture(self, landmarks):
        """根据手部关键点分类手势"""
        # 获取关键点坐标
        tips = [landmarks.landmark[i] for i in [4, 8, 12, 16, 20]]  # 指尖
        pips = [landmarks.landmark[i] for i in [3, 6, 10, 14, 18]]  # 指间关节

        # 判断手指是否伸直
        fingers = []
        fingers.append(tips[0].x < pips[0].x)  # 大拇指
        for i in range(1, 5):
            fingers.append(tips[i].y < pips[i].y)  # 其他四指

        # 手势分类
        if all(fingers):
            return "open_palm"  # 手掌张开 - 停止
        elif not any(fingers):
            return "fist"  # 握拳 - 确认
        elif fingers == [False, True, False, False, False]:
            return "point_up"  # 食指向上 - 上升
        elif fingers == [False, True, True, False, False]:
            return "peace"  # V字手势 - 拍照
        elif fingers == [True, False, False, False, False]:
            return "thumb_up"  # 竖拇指 - 上升
        else:
            return "unknown"
```

### 2.2 动态手势识别

```python
class DynamicGestureRecognizer:
    """动态手势识别（挥手、推拉等）"""

    def __init__(self):
        self.position_history = []
        self.history_length = 15

    def recognize(self, hand_landmarks):
        """识别动态手势"""
        # 记录手部位置
        wrist = hand_landmarks.landmark[0]
        self.position_history.append((wrist.x, wrist.y, time.time()))

        # 保持历史长度
        if len(self.position_history) > self.history_length:
            self.position_history.pop(0)

        if len(self.position_history) < 5:
            return None

        # 分析运动轨迹
        dx = self.position_history[-1][0] - self.position_history[0][0]
        dy = self.position_history[-1][1] - self.position_history[0][1]
        dt = self.position_history[-1][2] - self.position_history[0][2]

        speed = (dx**2 + dy**2) ** 0.5 / dt

        if speed > 0.5:  # 速度阈值
            if abs(dx) > abs(dy):
                if dx > 0:
                    return "wave_right"
                else:
                    return "wave_left"
            else:
                if dy > 0:
                    return "wave_down"
                else:
                    return "wave_up"

        return None
```

## 3. 体态识别

### 3.1 身体姿态估计

```python
class PoseEstimator:
    """基于 MediaPipe 的身体姿态估计"""

    def __init__(self):
        self.mp_pose = mp.solutions.pose
        self.pose = self.mp_pose.Pose(
            static_image_mode=False,
            min_detection_confidence=0.5
        )

    def estimate(self, frame):
        """估计身体姿态"""
        rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        results = self.pose.process(rgb)

        if results.pose_landmarks:
            landmarks = results.pose_landmarks.landmark
            pose_command = self._interpret_pose(landmarks)
            return pose_command

        return None

    def _interpret_pose(self, landmarks):
        """解释姿态为无人机指令"""
        # 举手检测
        left_hand_up = landmarks[self.mp_pose.PoseLandmark.LEFT_WRIST].y < \
                       landmarks[self.mp_pose.PoseLandmark.LEFT_SHOULDER].y
        right_hand_up = landmarks[self.mp_pose.PoseLandmark.RIGHT_WRIST].y < \
                        landmarks[self.mp_pose.PoseLandmark.RIGHT_SHOULDER].y

        if left_hand_up and right_hand_up:
            return {"command": "hover", "description": "双手举起 - 悬停"}
        elif left_hand_up:
            return {"command": "turn_left", "description": "左手举起 - 左转"}
        elif right_hand_up:
            return {"command": "turn_right", "description": "右手举起 - 右转"}

        return None
```

## 4. 手势控制系统集成

### 4.1 完整的手势控制流程

```python
class GestureControlSystem:
    """手势控制系统"""

    def __init__(self, flight_controller):
        self.fc = flight_controller
        self.gesture_recognizer = GestureRecognizer()
        self.pose_estimator = PoseEstimator()
        self.command_buffer = []
        self.confirmation_required = True

    def run(self):
        """运行手势控制循环"""
        cap = cv2.VideoCapture(0)

        while True:
            ret, frame = cap.read()
            if not ret:
                continue

            # 手势识别
            gesture_result = self.gesture_recognizer.recognize(frame)

            if gesture_result["gesture"]:
                command = self._gesture_to_command(gesture_result["gesture"])

                if command:
                    if self.confirmation_required:
                        # 需要确认的指令
                        self._request_confirmation(command)
                    else:
                        # 直接执行
                        self._execute_command(command)

    def _gesture_to_command(self, gesture):
        """将手势转换为飞控指令"""
        mapping = {
            "open_palm": {"action": "hover", "params": {}},
            "fist": {"action": "confirm", "params": {}},
            "thumb_up": {"action": "altitude_change", "params": {"delta": 2}},
            "point_up": {"action": "altitude_change", "params": {"delta": 5}},
            "wave_left": {"action": "yaw", "params": {"angle": -30}},
            "wave_right": {"action": "yaw", "params": {"angle": 30}},
            "peace": {"action": "capture_photo", "params": {}},
        }
        return mapping.get(gesture)
```

## 5. 安全考虑

### 5.1 手势控制的安全机制

| 安全机制 | 描述 |
|---------|------|
| 确认手势 | 关键指令需要确认手势（如握拳确认） |
| 超时取消 | 手势中断后自动取消待执行指令 |
| 紧急停止 | 特定手势（双手交叉）立即停止所有操作 |
| 距离限制 | 手势控制只在近距离有效 |
| 视线确认 | 操作员必须能看到无人机 |

<summary>参考答案</summary>

**1.** 手势优势：(1) 无需设备，直接用手；(2) 直觉，学习成本低；(3) 安静环境也能用。手势劣势：(1) 距离限制（需要在摄像头视野内）；(2) 天气影响（戴手套时困难）；(3) 精确性不如遥控器；(4) 只能表达简单指令。

**2.** 策略：(1) 置信度阈值 — 低于阈值的识别结果忽略；(2) 连续帧确认 — 同一手势连续多帧才确认；(3) 确认机制 — 关键指令需要确认手势；(4) 视觉反馈 — 在画面上显示识别结果，让操作员确认。

**3.** 适合场景：(1) 近距离航拍指挥；(2) 嘈杂环境（语音不可用）；(3) 需要快速响应的场景；(4) 多人协作（一个指挥一个飞）。

**4.** 设计原则：(1) 映射到自然动作（推=前进，拉=后退）；(2) 一只手能完成所有基本操作；(3) 有明确的"激活"和"停止"手势；(4) 避免容易混淆的手势；(5) 考虑文化差异（不同文化的手势含义不同）。

**5.** 融合方案：(1) 语音用于任务级指令（"巡逻A区域"）；(2) 手势用于实时微调（"往左一点"）；(3) 语音确认手势指令（"确认降落吗？"）；(4) 冲突时以语音为主（语音优先级更高）。
