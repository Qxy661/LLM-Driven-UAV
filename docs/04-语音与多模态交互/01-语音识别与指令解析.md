## 1. 语音控制的优势

### 1.1 为什么需要语音控制？

| 控制方式 | 优势 | 局限 |
|---------|------|------|
| 遥控器 | 精确、实时 | 需要双手、学习成本 |
| 手机 App | 界面直观 | 需要看屏幕 |
| 语音控制 | 解放双手、直觉 | 噪声干扰、口音问题 |
| 手势控制 | 距离近时直觉 | 距离远时不可见 |

```
场景 1: 航拍指挥
```

## 2. Whisper 语音识别

### 2.1 Whisper 模型介绍

Whisper（Radford et al., 2022）是 OpenAI 开源的通用语音识别模型：

| 模型 | 参数量 | 英文WER | 中文WER | 速度 |
|------|--------|---------|---------|------|
| tiny | 39M | 7.6% | 14.7% | 极快 |
| base | 74M | 5.4% | 10.8% | 快 |
| small | 244M | 4.3% | 8.1% | 中等 |
| medium | 769M | 3.5% | 6.5% | 较慢 |
| large-v3 | 1550M | 2.7% | 4.8% | 慢 |

### 2.2 Whisper 使用示例

```python
import whisper
import numpy as np

class VoiceRecognizer:
    """基于 Whisper 的语音识别器"""

    def __init__(self, model_size="medium"):
        self.model = whisper.load_model(model_size)

    def recognize(self, audio_path):
        """识别音频文件"""
        result = self.model.transcribe(
            audio_path,
            language="zh",  # 指定中文
            task="transcribe"
        )
        return {
            "text": result["text"],
            "language": result["language"],
            "segments": result["segments"]
        }

    def recognize_stream(self, audio_chunk):
        """流式识别（实时）"""
        # 将音频块转换为 Whisper 输入格式
        audio = whisper.pad_or_trim(audio_chunk)
        mel = whisper.log_mel_spectrogram(audio).to(self.model.device)

        # 推理
        options = whisper.DecodingOptions(
            language="zh",
            without_timestamps=True
        )
        result = whisper.decode(self.model, mel, options)
        return result.text
```

### 2.3 实时语音识别

```python
import pyaudio
import wave
import threading

class RealTimeVoiceRecognizer:
    """实时语音识别器"""

    def __init__(self, model_size="medium", sample_rate=16000):
        self.model = whisper.load_model(model_size)
        self.sample_rate = sample_rate
        self.is_listening = False
        self.audio_buffer = []

    def start_listening(self, callback):
        """开始监听麦克风"""
        self.is_listening = True
        self.callback = callback

        # 启动录音线程
        self.record_thread = threading.Thread(target=self._record_loop)
        self.record_thread.start()

        # 启动识别线程
        self.recognize_thread = threading.Thread(target=self._recognize_loop)
        self.recognize_thread.start()

    def _record_loop(self):
        """录音循环"""
        p = pyaudio.PyAudio()
        stream = p.open(
            format=pyaudio.paFloat32,
            channels=1,
            rate=self.sample_rate,
            input=True,
            frames_per_buffer=1024
        )

        while self.is_listening:
            data = stream.read(1024)
            audio_chunk = np.frombuffer(data, dtype=np.float32)
            self.audio_buffer.extend(audio_chunk)

        stream.stop_stream()
        stream.close()
        p.terminate()

    def _recognize_loop(self):
        """识别循环"""
        while self.is_listening:
            if len(self.audio_buffer) >= self.sample_rate * 2:  # 2秒音频
                # 取出音频数据
                audio_data = np.array(self.audio_buffer[:self.sample_rate * 2])
                self.audio_buffer = self.audio_buffer[self.sample_rate:]

                # 识别
                audio = whisper.pad_or_trim(audio_data)
                mel = whisper.log_mel_spectrogram(audio).to(self.model.device)
                options = whisper.DecodingOptions(language="zh")
                result = whisper.decode(self.model, mel, options)

                if result.text.strip():
                    self.callback(result.text)
```

## 3. 噪声鲁棒性

### 3.1 无人机噪声特点

```
无人机噪声源:
├── 电机噪声 (高频，持续)
├── 螺旋桨气动噪声 (宽频)
├── 风噪 (低频)
└── 振动噪声 (与转速相关)

噪声强度: 70-90 dB (近距离)
语音强度: 60-80 dB (正常说话)

信噪比 (SNR): 可能为负值！
```

### 3.2 降噪策略

| 策略 | 方法 | 效果 |
|------|------|------|
| 硬件降噪 | 定向麦克风 | 中等 |
| 软件降噪 | RNNoise 等 | 良好 |
| 远场拾音 | 麦克风阵列 | 良好 |
| 模型鲁棒 | Whisper 本身 | 良好 |
| 降噪耳机 | 操作员佩戴 | 很好 |

### 3.3 RNNoise 降噪

```python
import noisereduce as nr
import numpy as np

class NoiseRobustRecognizer:
    """噪声鲁棒的语音识别器"""

    def __init__(self, model_size="medium"):
        self.model = whisper.load_model(model_size)

    def recognize_noisy(self, audio_data, sample_rate=16000):
        """识别含噪声的音频"""
        # 1. 降噪处理
        reduced_noise = nr.reduce_noise(
            y=audio_data,
            sr=sample_rate,
            stationary=False  # 非稳态噪声
        )

        # 2. 语音活动检测
        if not self._has_speech(reduced_noise):
            return {"text": "", "has_speech": False}

        # 3. 识别
        audio = whisper.pad_or_trim(reduced_noise)
        mel = whisper.log_mel_spectrogram(audio).to(self.model.device)
        options = whisper.DecodingOptions(language="zh")
        result = whisper.decode(self.model, mel, options)

        return {"text": result.text, "has_speech": True}

    def _has_speech(self, audio, threshold=0.01):
        """简单的语音活动检测"""
        energy = np.mean(audio ** 2)
        return energy > threshold
```

## 4. 指令解析

### 4.1 语音指令提取

```python
class VoiceCommandExtractor:
    """语音指令提取器"""

    def __init__(self, llm_client):
        self.llm = llm_client

    def extract_command(self, raw_text):
        """从原始语音文本中提取指令"""
        prompt = f"""从以下语音识别结果中提取无人机指令。

原始语音: "{raw_text}"

注意:
1. 语音识别可能有错误，请尝试纠正
2. 提取核心指令意图
3. 忽略语气词和无关内容
4. 如果是无效输入（噪声、无关对话），返回 null

输出 JSON:
{{
    "corrected_text": "纠正后的文本",
    "intent": "指令意图",
    "parameters": {{}},
    "confidence": 0.0-1.0,
    "is_valid_command": true/false
}}"""

        return json.loads(self.llm.generate(prompt))
```

<summary>参考答案</summary>

**1.** 多层防护：(1) 硬件层 — 使用定向麦克风和降噪外壳；(2) 信号层 — RNNoise 实时降噪；(3) 识别层 — 使用 large-v3 模型（最鲁棒）；(4) 理解层 — LLM 纠正识别错误；(5) 确认层 — 关键指令要求语音确认（"你确定要降落吗？"）。

**2.** 设计要点：(1) 唤醒词检测 — "嘿，无人机" 激活系统；(2) 语音活动检测 — 区分语音和噪声；(3) 上下文管理 — 维护对话历史；(4) 打断支持 — 用户可以随时打断系统响应；(5) 反馈机制 — 系统用语音回复确认。

**3.** 安全问题：(1) "飞到10米"被识别为"飞到70米" — 高度错误；(2) "降落"被识别为其他词 — 可能不执行；(3) 环境噪声被误识别为指令。防护：(1) 关键指令二次确认；(2) 安全约束硬编码（即使识别为70米也限制在120米以下）；(3) 显示识别结果让操作员确认。

**4.** 策略：(1) 使用 Whisper 的多语言能力（本身就支持多种口音）；(2) 微调 — 用特定口音的数据微调模型；(3) 用户自适应 — 学习用户的说话习惯；(4) 提供文字确认 — 语音识别后显示文字，让用户确认。

**5.** 完整架构：(1) 麦克风阵列采集音频；(2) RNNoise 降噪；(3) Whisper 语音识别；(4) LLM 指令解析和纠错；(5) 安全检查层；(6) 任务规划和执行；(7) TTS 语音反馈；(8) 持续监听下一条指令。
