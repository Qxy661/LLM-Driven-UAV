## 1. 交互设计原则

### 1.1 核心原则

| 原则 | 描述 | 示例 |
|------|------|------|
| 直觉性 | 操作符合用户直觉 | "飞高一点" 就是升高 |
| 反馈性 | 每个操作都有反馈 | 语音+视觉确认 |
| 安全性 | 关键操作需确认 | 降落前确认 |
| 容错性 | 允许用户犯错 | 误操作可撤销 |
| 渐进性 | 从简单到复杂 | 新手引导 |

### 1.2 交互模式

```
模式 1: 命令式
  用户: "起飞"
  系统: "收到，起飞中"

模式 2: 对话式
  用户: "帮我看看那边"
  系统: "你想查看哪个方向？"
  用户: "教学楼那边"
  系统: "好的，正在飞往教学楼"

模式 3: 混合式
  用户: "起飞" → 系统执行
  用户: "往左飞一点" → 系统微调
  用户: "拍张照片" → 系统执行
```

## 2. 自然语言 UI

### 2.1 对话界面设计

```python
class ConversationalUI:
    """对话式交互界面"""

    def __init__(self, llm_client):
        self.llm = llm_client
        self.conversation_history = []
        self.state = "idle"

    def process_input(self, user_input):
        """处理用户输入"""
        # 添加到对话历史
        self.conversation_history.append({
            "role": "user",
            "content": user_input
        })

        # LLM 理解和响应
        prompt = f"""你是一个友好的无人机操控助手。
请理解用户的意图并给出适当的响应。

对话历史:
{self._format_history()}

当前状态: {self.state}

请:
1. 理解用户意图
2. 如果是任务指令，确认并开始执行
3. 如果是状态查询，提供当前信息
4. 如果是闲聊，友好回应
5. 如果不明确，询问澄清"""

        response = self.llm.generate(prompt)
        self.conversation_history.append({
            "role": "assistant",
            "content": response
        })

        return response
```

## 3. 信任校准

### 3.1 信任度模型

```python
class TrustCalibrator:
    """信任校准器"""

    def __init__(self):
        self.trust_level = 0.5  # 初始信任度 0-1
        self.history = []

    def update(self, event_type, outcome):
        """根据事件更新信任度"""
        if event_type == "task_success":
            self.trust_level = min(1.0, self.trust_level + 0.1)
        elif event_type == "task_failure":
            self.trust_level = max(0.0, self.trust_level - 0.2)
        elif event_type == "safety_violation":
            self.trust_level = max(0.0, self.trust_level - 0.3)
        elif event_type == "correct_warning":
            self.trust_level = min(1.0, self.trust_level + 0.15)

        self.history.append({
            "time": time.time(),
            "event": event_type,
            "outcome": outcome,
            "trust_level": self.trust_level
        })

    def get_autonomy_level(self):
        """根据信任度确定自主性级别"""
        if self.trust_level > 0.8:
            return "high"  # 高自主性
        elif self.trust_level > 0.5:
            return "medium"  # 中自主性
        else:
            return "low"  # 低自主性，需要更多确认
```

### 3.2 自适应界面

```python
class AdaptiveInterface:
    """自适应交互界面"""

    def __init__(self, trust_calibrator):
        self.trust = trust_calibrator

    def get_confirmation_level(self, action_type):
        """根据信任度决定确认级别"""
        autonomy = self.trust.get_autonomy_level()

        if action_type in ["takeoff", "land", "emergency"]:
            return "always_confirm"  # 关键操作始终确认

        if autonomy == "high":
            return "auto_execute"  # 自动执行
        elif autonomy == "medium":
            return "notify_only"  # 仅通知
        else:
            return "require_confirm"  # 需要确认
```

## 4. 多通道交互

### 4.1 交互通道

| 通道 | 输入 | 输出 | 适用场景 |
|------|------|------|---------|
| 语音 | 语音指令 | 语音反馈 | 手被占用时 |
| 触控 | 屏幕操作 | 界面显示 | 精确控制时 |
| 手势 | 手势指令 | 视觉反馈 | 近距离时 |
| 键盘 | 快捷键 | 界面显示 | 快速操作时 |

### 4.2 通道融合

```python
class MultimodalInteractionManager:
    """多通道交互管理"""

    def __init__(self):
        self.voice_handler = VoiceHandler()
        self.touch_handler = TouchHandler()
        self.gesture_handler = GestureHandler()

    def process_input(self, channel, data):
        """处理来自不同通道的输入"""
        if channel == "voice":
            return self.voice_handler.process(data)
        elif channel == "touch":
            return self.touch_handler.process(data)
        elif channel == "gesture":
            return self.gesture_handler.process(data)
```

## 5. 新手引导

### 5.1 引导流程

```python
class OnboardingGuide:
    """新手引导系统"""

    def __init__(self, llm_client):
        self.llm = llm_client
        self.step = 0
        self.steps = [
            "welcome",      # 欢迎
            "basic_flight", # 基本飞行
            "navigation",   # 导航
            "tasks",        # 任务
            "safety"        # 安全
        ]

    def get_current_instruction(self):
        """获取当前引导步骤的说明"""
        prompt = f"""你是一个友好的无人机飞行教练。
请为新手用户提供第 {self.step + 1} 步的引导说明。

引导阶段: {self.steps[self.step]}

请用简洁友好的语言说明:
1. 这一步要学什么
2. 如何操作
3. 注意事项

保持简短，适合语音播报。"""

        return self.llm.generate(prompt)
```

## 思考题

1. 对话式交互相比传统 GUI 有什么优势和劣势？
2. 如何设计一个既能满足新手又能满足专家的交互界面？
3. 信任校准对无人机安全操作有什么意义？
4. 如何处理用户在紧急情况下的交互需求？
5. 设计一个完整的无人机人机交互系统原型。

<details>
<summary>参考答案</summary>

**1.** 对话式优势：(1) 学习成本低（自然语言）；(2) 支持复杂指令（一句话描述复杂任务）；(3) 支持模糊指令（"看看那边"）。劣势：(1) 精确性不如 GUI（难以精确控制参数）；(2) 噪声环境不可靠；(3) 不适合高频操作。

**2.** 渐进式设计：(1) 新手模式 — 简化的界面，只有基本操作按钮，详细引导；(2) 标准模式 — 完整功能，中等复杂度；(3) 专家模式 — 所有功能，快捷键支持。用户可以随时切换模式。

**3.** 信任校准的意义：(1) 防止过度信任 — 用户过于信任系统可能导致忽视异常；(2) 防止信任不足 — 用户不信任系统会频繁手动干预，降低效率；(3) 动态调整 — 系统表现好时增加自主性，表现差时增加人类确认。

**4.** 紧急交互：(1) 一键紧急停止按钮（始终可见）；(2) 语音紧急指令优先处理（"停！"）；(3) 紧急模式下简化界面，只显示关键信息；(4) 紧急操作不需要确认（但需要安全检查）。

**5.** 系统原型：(1) 语音+触控双输入通道；(2) 实时视频+状态仪表盘；(3) 对话式任务管理；(4) 快捷指令按钮；(5) 自适应确认级别；(6) 紧急停止按钮；(7) 新手引导系统。
