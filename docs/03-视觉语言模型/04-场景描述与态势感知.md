## 1. 态势感知概述

### 1.1 三级态势感知模型

Endsley 的态势感知模型在无人机场景中的应用：

| 级别 | 描述 | VLM 能力 |
|------|------|---------|
| SA1: 感知 | 检测环境中的元素 | 目标检测、场景分类 |
| SA2: 理解 | 理解当前状态的含义 | 场景描述、异常识别 |
| SA3: 预测 | 预测未来状态 | 趋势推理、风险预测 |

### 1.2 VLM 赋能的态势感知

```
传感器数据
├── 摄像头图像 ─┐
├── GPS 位置 ───┤
├── IMU 姿态 ───┼──→ VLM ──→ 态势感知报告
├── 气象数据 ───┤
└── 地图数据 ───┘

VLM 统一理解所有信息，生成自然语言态势描述
```

## 2. 实时场景描述

### 2.1 流式场景描述

```python
class StreamingSceneDescriber:
    """流式场景描述器"""

    def __init__(self, vlm_client, llm_client):
        self.vlm = vlm_client
        self.llm = llm_client
        self.scene_history = []
        self.update_interval = 5  # 每5秒更新一次

    def describe_current_scene(self, image, gps, compass):
        """描述当前场景"""
        prompt = f"""你是一个无人机态势感知系统。
请描述当前观察到的场景。

当前位置: ({gps['lat']}, {gps['lon']})
朝向: {compass}度
图像: [已提供]

请简洁描述:
1. 当前位置上方的环境
2. 主要可见目标
3. 值得注意的情况
4. 一句话总结"""

        description = self.vlm.analyze(image, prompt)
        self.scene_history.append({
            "time": time.time(),
            "gps": gps,
            "description": description
        })
        return description

    def get_scene_summary(self, duration=60):
        """获取一段时间的场景总结"""
        recent = [s for s in self.scene_history
                  if time.time() - s["time"] < duration]

        prompt = f"""总结以下无人机飞行过程中的场景变化:

{json.dumps(recent, ensure_ascii=False)}

请总结:
1. 飞过了哪些区域
2. 场景的主要变化
3. 发现的关键信息"""

        return self.llm.generate(prompt)
```

## 3. 威胁识别

### 3.1 安全威胁检测

```python
def detect_threats(image, context, vlm_client):
    """检测潜在安全威胁"""

    prompt = f"""你是一个无人机安全监控系统。
请分析当前图像，识别可能的安全威胁。

巡检区域: {context['area']}
巡检目的: {context['purpose']}
当前时间: {context['time']}

请检查:
1. 未授权人员进入
2. 可疑车辆或物品
3. 围栏/边界破坏
4. 异常活动
5. 自然灾害迹象

对每个威胁，评估:
- 威胁类型
- 严重程度 (低/中/高/紧急)
- 置信度
- 建议响应"""

    return vlm_client.analyze(image, prompt)
```

### 3.2 威胁等级评估

```

         低影响    中影响    高影响
```

## 4. 态势报告生成

### 4.1 结构化态势报告

```python
class SituationalReportGenerator:
    """态势报告生成器"""

    def generate_report(self, flight_data, vlm_analyses):
        """生成完整的态势报告"""
        prompt = f"""基于以下飞行数据和视觉分析结果，生成态势报告。

飞行信息:
- 时间: {flight_data['time']}
- 区域: {flight_data['area']}
- 航线: {flight_data['route']}

视觉分析:
{json.dumps(vlm_analyses, ensure_ascii=False)}

请生成结构化报告，包含:
1. 执行摘要
2. 区域概况
3. 关键发现
4. 威胁评估
5. 建议行动
6. 飞行状态总结"""

        return self.llm.generate(prompt)
```

## 5. 多机协同态势感知

### 5.1 分布式态势融合

```python
class MultiDroneSituationalAwareness:
    """多无人机态势融合"""

    def __init__(self, llm_client):
        self.llm = llm_client
        self.uav_reports = {}

    def add_report(self, uav_id, report):
        self.uav_reports[uav_id] = report

    def fuse_situations(self):
        """融合多架无人机的态势报告"""
        prompt = f"""融合以下多架无人机的态势报告，生成统一态势图。

{json.dumps(self.uav_reports, ensure_ascii=False)}

请生成:
1. 统一的区域态势描述
2. 各区域的综合评估
3. 跨区域的关联分析
4. 整体威胁评估
5. 协同行动建议"""

        return self.llm.generate(prompt)
```

## 思考题

1. 态势感知的三个层级（感知、理解、预测）中，VLM 最擅长哪个？为什么？
2. 如何设计实时场景描述的更新频率？太频繁或太稀疏各有什么问题？
3. 在威胁识别中，如何平衡检测灵敏度和误报率？
4. 多机协同时，如何融合不同视角的态势信息？
5. 设计一个完整的态势感知系统架构。

<details>
<summary>参考答案</summary>

**1.** VLM 最擅长 SA2（理解）— 它能将原始的视觉信息转化为语义描述，理解"这意味着什么"。SA1（感知）VLM 也能做，但传统 CV 在精确检测方面可能更好。SA3（预测）VLM 有一定能力，但不如专门的预测模型。

**2.** 频率取决于任务阶段：巡航时 5-10 秒更新一次；执行任务时 1-2 秒更新一次；紧急情况下实时更新。太频繁会消耗计算资源和带宽；太稀疏可能错过重要变化。智能策略：只在检测到变化时才生成详细描述。

**3.** 策略：(1) 使用多级阈值 — 高置信度直接告警，低置信度标记为观察；(2) 时序验证 — 连续多帧检测到才确认；(3) 上下文验证 — 结合位置和时间判断合理性；(4) 人类确认 — 对不确定的威胁请求人类判断。

**4.** 融合策略：(1) 地理注册 — 将各无人机的发现映射到统一地图；(2) 时间对齐 — 确保信息时效性；(3) 冲突解决 — 不同无人机对同一区域有不同判断时如何处理；(4) 互补利用 — 利用不同视角的优势（高空概览 vs 低空细节）。

**5.** 完整架构：(1) 数据采集层 — 多传感器输入；(2) 预处理层 — 图像增强、坐标转换；(3) VLM 分析层 — 场景描述、目标检测、异常识别；(4) 态势融合层 — 多源信息融合；(5) 威胁评估层 — 风险等级计算；(6) 报告生成层 — 结构化报告输出；(7) 人机交互层 — 实态势展示和人交互。

</details>
