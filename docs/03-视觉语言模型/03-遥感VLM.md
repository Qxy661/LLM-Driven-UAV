本文档介绍视觉语言模型在遥感领域的应用，包括卫星/航拍图像分析、变化检测和灾害评估。

---

## 1. 遥感 VLM 概述

### 1.1 遥感图像的特点

| 特点 | 描述 | 挑战 |
|------|------|------|
| 俯视视角 | 自上而下拍摄 | 与日常图像视角差异大 |
| 大幅面 | 单张图像覆盖大区域 | 需要处理高分辨率 |
| 多光谱 | 可见光、红外、多光谱 | 需要多模态融合 |
| 时序性 | 同一区域多次拍摄 | 需要变化检测 |
| 地理标注 | 每个像素对应真实坐标 | 需要精确的地理参考 |

### 1.2 遥感 VLM 的能力

```
传统遥感分析:                    遥感 VLM:
├── 土地利用分类                 ├── 自然语言描述场景
├── 目标检测 (YOLO)             ├── 开放词汇目标检测
├── 变化检测 (像素级)           ├── 语义级变化理解
├── 需要专业软件                ├── 自然语言交互
└── 需要专业知识                └── 降低使用门槛
```

## 2. 航拍图像分析

### 2.1 土地利用分析

```python
def analyze_land_use(image, vlm_client):
    """分析航拍图像的土地利用情况"""

    prompt = """请分析这张航拍图像的土地利用情况。

请识别并估算以下类别的面积占比:
1. 建筑用地（住宅、商业、工业）
2. 交通用地（道路、停车场）
3. 绿地（公园、农田、林地）
4. 水域（河流、湖泊、水库）
5. 未开发用地（荒地、工地）

对每个类别，提供:
- 面积估算（百分比）
- 空间分布特征
- 代表性区域描述"""

    return vlm_client.analyze(image, prompt)
```

## 3. 变化检测

### 3.1 语义级变化检测

```python
def detect_changes(before_image, after_image, vlm_client):
    """语义级变化检测"""

    prompt = """比较这两张同一区域在不同时间拍摄的航拍图像。

图像A (早期): [已提供]
图像B (近期): [已提供]

请识别并描述:
1. 新增的建筑物或结构
2. 消失的建筑物或结构
3. 土地利用类型变化
4. 植被变化（新增/减少）
5. 水域变化
6. 道路变化
7. 其他显著变化

对每个变化，估计变化的时间范围和可能原因。"""

    return vlm_client.analyze_multi([before_image, after_image], prompt)
```

def multispectral_analysis(rgb_image, nir_image, vlm_client):

## 思考题

1. 遥感 VLM 与通用 VLM 有什么区别？为什么需要专门的遥感 VLM？
2. 如何处理遥感图像的大尺寸问题（单张图像可能有数亿像素）？
3. 变化检测中，如何区分"真实变化"和"季节性变化"？
4. 灾害评估场景中，VLM 的响应速度有多重要？如何优化？
5. 设计一个基于 VLM 的农业监测系统。

<details>
<summary>参考答案</summary>

**1.** 主要区别：(1) 视角 — 遥感是俯视，通用 VLM 训练数据以平视为主；(2) 尺度 — 遥感目标可能很小（车辆、人）；(3) 光谱 — 遥感可能包含红外等非可见光；(4) 语义 — 遥感有专业术语（如"NDVI"）。需要微调或使用专门训练的遥感 VLM。

**2.** 处理策略：(1) 切片 — 将大图切成小块分别分析，再汇总；(2) 金字塔 — 从低分辨率概览到高分辨率细节；(3) 注意力聚焦 — 先用低分辨率找到感兴趣区域，再用高分辨率分析；(4) 使用支持高分辨率输入的模型（如动态分辨率 VLM）。

**3.** 方法：(1) 使用同期历史数据对比（如 2024 春 vs 2023 春）；(2) 利用多光谱数据区分（植被季节变化有规律）；(3) VLM 可以理解"这是季节性落叶"还是"树木被砍伐"；(4) 建立基线数据库，存储各季节的标准图像。

**4.** 灾害评估对速度要求极高 — 黄金救援时间有限。优化：(1) 使用轻量 VLM 或量化模型；(2) 优先分析关键区域（人员被困点）；(3) 边采集边分析，不等全部图像收集完；(4) 使用边缘计算减少传输延迟。

**5.** 农业监测系统：(1) 定期飞行采集多光谱图像；(2) VLM 分析作物健康状况（颜色、密度、异常）；(3) 与历史数据对比检测变化；(4) 生成分区管理建议（哪些区域需要灌溉/施肥/除虫）；(5) 自动化报告推送给农户。

</details>
