## 1. 视觉导航概述

### 1.1 导航方式对比

| 导航方式 | 输入 | 优势 | 局限 |
|---------|------|------|------|
| GPS 导航 | 坐标 | 简单可靠 | 需要精确坐标，室内不可用 |
| 视觉 SLAM | 摄像头 | 不依赖 GPS | 需要预建地图 |
| 语言导航 | 自然语言 | 直观易用 | 需要视觉理解 |
| 混合导航 | 多种 | 互补 | 系统复杂 |

### 1.2 语言引导导航的优势

```
传统导航:
  用户: "飞到 (31.2345, 121.4567, 15)"  ← 需要知道精确坐标

语言导航:
  用户: "飞到那栋红色建筑旁边"            ← 直觉描述
  用户: "沿着河边向北飞"                  ← 相对描述
  用户: "找到停车场里那辆白色SUV"          ← 目标搜索
```

## 2. 语言引导导航

### 2.1 导航系统架构

```python
class LanguageGuidedNavigator:
    """语言引导的导航系统"""

    def __init__(self, vlm_client, vla_model, flight_controller):
        self.vlm = vlm_client
        self.vla = vla_model
        self.fc = flight_controller

    def navigate(self, instruction):
        """执行语言引导的导航"""
        while not self._arrived():
            # 获取当前图像
            image = self.fc.get_camera_image()

            # VLM 分析当前画面与目标的关系
            analysis = self._analyze_navigation(image, instruction)

            # 生成导航动作
            if analysis["target_visible"]:
                # 目标可见，直接导航
                action = self._navigate_to_target(analysis["target_position"])
            else:
                # 目标不可见，搜索
                action = self._search_for_target(analysis)

            # 执行动作
            self.fc.execute(action)

    def _analyze_navigation(self, image, instruction):
        """分析导航状态"""
        prompt = f"""你是一个无人机视觉导航系统。

导航指令: {instruction}
当前图像: [已提供]

请分析:
1. 目标是否在当前视野中？
2. 如果是，目标在图像中的位置（左/中/右，上/中/下）
3. 目标的估计距离
4. 相对于无人机的方向
5. 建议的飞行方向

输出 JSON 格式。"""

        return json.loads(self.vlm.analyze(image, prompt))
```

## 3. 视觉目标定位

### 3.1 目标定位流程

```python
class VisualTargetLocator:
    """视觉目标定位器"""

    def locate(self, image, target_description, vlm_client):
        """在图像中定位目标"""
        prompt = f"""请在图像中找到以下目标:

目标描述: {target_description}

请提供:
1. 目标是否在图像中
2. 目标的边界框坐标 (归一化坐标 0-1)
   - x_min, y_min, x_max, y_max
3. 目标的中心点坐标
4. 置信度
5. 目标的简要描述

输出 JSON 格式。"""

        result = json.loads(vlm_client.analyze(image, prompt))

        if result["found"]:
            # 转换为 GPS 坐标
            gps = self._pixel_to_gps(
                result["center"]["x"],
                result["center"]["y"],
                self.fc.get_state()
            )
            result["gps_estimate"] = gps

        return result

    def _pixel_to_gps(self, px, py, state):
        """将像素坐标转换为 GPS 坐标"""
        # 简化的透视变换
        lat = state["lat"] + (py - 0.5) * self.meters_per_pixel_y / 111000
        lon = state["lon"] + (px - 0.5) * self.meters_per_pixel_x / (111000 * cos(radians(state["lat"])))
        return {"lat": lat, "lon": lon}
```

## 思考题

1. 语言引导导航相比 GPS 导航有什么优势和劣势？
2. 如何处理目标描述模糊的情况（如"飞到那栋楼"有多栋楼）？
3. 视觉定位的精度受哪些因素影响？如何提高？
4. 设计一个搜索-确认-跟踪的完整视觉导航流程。
5. 如何处理视觉导航中的遮挡问题？

<details>
<summary>参考答案</summary>

**1.** 优势：(1) 不需要精确坐标，用户可以用自然语言描述；(2) 在 GPS 信号弱的环境（室内、城市峡谷）仍可工作；(3) 可以寻找动态目标（移动的人/车辆）。劣势：(1) 受天气和光照影响；(2) 定位精度不如 GPS；(3) 需要目标在视野内；(4) 计算开销大。

**2.** 策略：(1) 上下文推断 — 结合之前的对话判断用户指哪栋楼；(2) 主动询问 — "你是指左边的红色建筑还是右边的白色建筑？"；(3) 特征消歧 — 让 VLM 列出所有候选，请求用户确认；(4) 默认选择 — 如果只有一个最匹配的描述，自动选择。

**3.** 影响因素：(1) 图像质量（分辨率、模糊）；(2) 目标大小（远处小目标定位困难）；(3) 相机标定精度；(4) GPS/IMU 精度（用于坐标转换）。提高方法：(1) 使用高分辨率相机；(2) 多帧融合提高精度；(3) 精确的相机标定；(4) 与 GPS/IMU 融合。

**4.** 完整流程：(1) 搜索 — 按搜索模式飞行，VLM 持续分析画面；(2) 确认 — 检测到候选目标后，多角度验证；(3) 定位 — 确认后精确计算目标 GPS 坐标；(4) 接近 — 飞向目标，持续跟踪；(5) 到达 — 在目标附近悬停，执行后续任务。

**5.** 处理遮挡：(1) 多角度观察 — 从不同方向观察目标区域；(2) 高度调整 — 升高高度扩大视野；(3) 运动估计 — 即使目标暂时被遮挡，根据运动趋势预测位置；(4) VLM 推理 — "目标进入建筑后方，预计从另一侧出现"。

</details>
