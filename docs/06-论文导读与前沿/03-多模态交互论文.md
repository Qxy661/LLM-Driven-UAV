## 1. 语音识别论文

### 1.1 Whisper — 通用语音识别

```
Robust Speech Recognition via Large-Scale Weak Supervision
作者: Radford et al. (OpenAI)
年份: 2022
会议: ICML 2023

核心问题:
  训练一个通用、鲁棒的语音识别模型

方法概述:
  在 680,000 小时的多语言音频数据上训练
  Seq2seq 架构: 音频 → 文本
  多任务: 识别、翻译、时间戳

关键创新:
  超大规模弱监督训练
  多语言支持 (99 种语言)
  鲁棒性 (噪声、口音、专业术语)

实验结果:
  在多个基准上接近人类水平
  零样本泛化能力强

与无人机的关联:
  可以识别操作员的语音指令
  多语言支持适合国际使用
  鲁棒性适合户外噪声环境
```

> 📄 arXiv: [Robust Speech Recognition via Large-Scale Weak Supervision](https://arxiv.org/abs/2212.04356)

**Whisper 架构概述:**

```
输入: 30秒音频 → 80维 Mel 频谱图 (25ms窗口, 10ms步长)
      ↓
Transformer Encoder: 多层自注意力 (d_model=1024, n_head=16)
      ↓
Transformer Decoder: 自回归生成文本 token
      ↓
多任务输出格式: <|startoftranscript|><|语言|><|任务|>文本<|timestamp|><|endofseq|>

训练数据: 680,000 小时弱监督 (互联网音频+对应字幕)
多任务标签: <|transcribe|> 识别, <|translate|> 翻译
语言标签:   <|zh|> 中文, <|en|> 英文, <|ja|> 日文 ... (99种)
```

## 2. 语音合成论文

### 2.1 VITS — 端到端 TTS

```
Conditional Variational Autoencoder with Adversarial Learning for End-to-End Text-to-Speech
作者: Kim et al.
年份: 2021
会议: ICML 2021

核心问题:
  端到端的高质量语音合成

方法概述:
  VAE + GAN 架构
  文本 → 隐变量 → 波形
  端到端训练，不需要外部对齐

关键创新:
  端到端训练
  高质量、自然的语音
  支持多说话人

与无人机的关联:
  可以为无人机提供自然的语音反馈
  支持中文，适合国内使用
```

> 📄 arXiv: [Conditional Variational Autoencoder with Adversarial Learning for End-to-End Text-to-Speech (VITS)](https://arxiv.org/abs/2106.06103)

### 2.2 ChatTTS — 对话风格 TTS

```
ChatTTS: A Generative Speech Model for Daily Dialogue
作者: 2noise (开源社区项目)
年份: 2024
GitHub: https://github.com/2noise/ChatTTS

核心特点:
  专为对话场景设计
```

## 4. 多模态融合论文

### 4.1 Flamingo — 多模态少样本学习

```
Flamingo: a Visual Language Model for Few-Shot Learning
作者: Alayrac et al. (DeepMind)
年份: 2022
会议: NeurIPS 2022

核心问题:
  如何让 VLM 具有少样本学习能力

方法概述:
  Perceiver Resampler: 压缩视觉 token
  门控交叉注意力: 融合视觉和语言
  少样本提示: 在上下文中学习

关键创新:
  少样本视觉语言理解
  高效的视觉-语言融合
  支持多图像输入

与无人机的关联:
  少样本能力可以快速适应新场景
  多图像输入支持多角度分析
```

> 📄 arXiv: [Flamingo: a Visual Language Model for Few-Shot Learning](https://arxiv.org/abs/2204.14198)

## 思考题

1. Whisper 的大规模弱监督训练策略有什么启示？
2. 如何设计适合无人机场景的语音交互系统？
3. 手势控制相比语音控制有什么独特优势？
4. Flamingo 的少样本能力如何应用到无人机场景？
5. 如何结合多种交互方式设计无人机控制系统？

<details>
<summary>参考答案</summary>

**1.** 启示：(1) 数据规模比数据质量更重要（弱监督也能训练好模型）；(2) 多语言/多任务联合训练可以提升泛化能力；(3) 大模型具有强大的零样本能力。对无人机的启示：可以用大量公开的无人机视频数据训练视觉模型。

**2.** 设计要点：(1) 使用 Whisper 做语音识别（鲁棒性强）；(2) 使用 LLM 做指令理解（处理歧义）；(3) 使用 TTS 做语音反馈（自然对话）；(4) 支持唤醒词（避免误触发）；(5) 噪声抑制（户外环境）。

**3.** 手势优势：(1) 安静环境也能用（不需要发声）；(2) 更直觉（直接用手指示方向）；(3) 可以表达空间信息（指向具体位置）；(4) 不受语言限制。适合场景：近距离、需要快速响应、多人协作。

**4.** 应用：(1) 少样本适应新场景 — 只需要几张新环境的图像就能理解；(2) 快速学习新任务 — 通过几个示例学习新的巡检任务；(3) 跨环境迁移 — 从一个园区的经验迁移到另一个园区。

**5.** 融合设计：(1) 语音用于任务级指令（"巡逻A区域"）；(2) 手势用于实时微调（"往左一点"）；(3) 触屏用于精确控制（设置航点）；(4) 自然语言用于复杂查询（"电量还够飞多远"）；(5) 统一的意图理解层处理所有输入。

</details>
