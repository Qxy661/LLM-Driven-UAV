# VLM 感知流水线

```mermaid
graph LR
    subgraph 输入
        A[RGB 相机]
        B[红外相机]
        C[LiDAR]
        D[多光谱]
    end

    subgraph 预处理
        E[图像增强]
        F[去噪/校正]
        G[特征对齐]
    end

    subgraph VLM 分析
        H[视觉编码器<br/>ViT/CLIP]
        I[连接模块<br/>MLP/Q-Former]
        J[语言模型<br/>Llama/Qwen]
    end

    subgraph 输出
        K[场景描述]
        L[目标检测]
        M[异常识别]
        N[态势报告]
    end

    A --> E
    B --> E
    C --> F
    D --> F
    E --> G
    F --> G
    G --> H
    H --> I
    I --> J
    J --> K
    J --> L
    J --> M
    J --> N
```

## 模型选择决策树

```
需要 VLM 分析？
├── 需要最强性能？ → GPT-4V / Gemini (API)
├── 需要中文支持？ → Qwen-VL / InternVL2
├── 需要本地部署？
│   ├── GPU 24GB+？ → LLaVA-1.6 13B
│   ├── GPU 8-16GB？ → LLaVA-1.6 7B
│   └── GPU <8GB？ → MiniCPM-V / InternVL2-1B
└── 需要实时性？ → 轻量 VLM + 传统 CV 混合
```
