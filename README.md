# 大语言模型驱动的无人机自主系统 — 从LLM任务规划到多模态飞行智能

> 本项目是一套完整的中文技术教学文档，系统讲解如何利用大语言模型（LLM）、视觉语言模型（VLM）及多模态智能技术，构建下一代无人机自主飞行系统。

---

## 项目简介

随着 GPT-4V、LLaVA、Gemini 等多模态大模型的快速发展，人工智能正从"感知智能"迈向"认知智能"。在无人机（UAV）领域，这意味着：

- **自然语言任务规划**：用自然语言描述任务目标，LLM 自动分解为可执行的飞行计划
- **视觉语言理解**：VLM 赋予无人机"看懂"场景并用语言描述的能力
- **智能决策与重规划**：面对突发状况，LLM 可作为 fallback 规划器实时调整策略
- **多模态人机交互**：语音、手势、自然语言的融合，让操控无人机像对话一样简单

本项目从零开始，逐步构建"LLM + UAV"的完整技术栈，适合希望进入这一前沿交叉领域的学习者。

## 核心模型速览

本项目涉及的关键大模型：

| 模型 | 类型 | 核心能力 | 与 UAV 的关联 |
|------|------|---------|--------------|
| GPT-4V / GPT-4o | 多模态 LLM | 图文理解、推理、代码生成 | 任务规划、场景理解 |
| LLaVA 1.6 | 视觉语言模型 | 图像描述、视觉问答 | 航拍图像分析 |
| Gemini 1.5 Pro | 多模态长上下文 | 超长视频理解、多图推理 | 长航时视频分析 |
| Qwen-VL-Max | 中文 VLM | 中文图文理解 | 中文场景交互 |
| Whisper Large-v3 | 语音模型 | 高精度语音识别 | 语音指令解析 |
| Llama 3.1 70B | 开源 LLM | 长上下文推理 | 本地部署推理 |
| RT-2 | 视觉语言动作模型 | 视觉到动作映射 | 自主导航控制 |
| OpenVLA | 开源 VLA | 开源视觉动作映射 | UAV 动作生成 |
